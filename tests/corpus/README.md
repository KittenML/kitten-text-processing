This corpus contains **1,000 explicitly authored sentences**, stored as literal
UTF-8 lines (`category|input`), not generated by substituting numbers into a
programmatic template. English has 104 cases; each of the other 16 languages has
56. Parallel scenarios intentionally allow cross-language comparisons.

Languages: Arabic, Armenian, Chinese, English, French, German, Hindi, Hungarian,
Italian, Japanese, Kinyarwanda, Korean, Portuguese, Russian, Spanish, Swedish,
and Vietnamese. These are all written-to-spoken languages exposed by the
pinned NeMo 1.2.0 Normalizer, not all languages spoken in the world.

Coverage includes numbers, ordinals, decimals, fractions, currencies, dates,
times, units, email/URLs/phones, punctuation, plain text, and mixed inputs.
Non-Latin scripts and Hindi/Arabic native digits are included. Inputs include
forms that the upstream grammar handles poorly: these must not be silently
removed to inflate agreement.

`*.reference.json` contains actual outputs captured by the pinned NeMo oracle,
including errors. Expected outputs are NOT generated by this library, manually
corrected, or stored in the runtime package. See `tools/benchmark.py` to reproduce.

This is a development/regression corpus, not an untouched statistical test set.
The corpus was used to debug generic decoder ordering and floating-point behavior.
It is not a native-speaker audit of linguistic accuracy. Exact parity can include
incorrect upstream readings or unchanged numeric text. Russian selects one
lowest-weight reading without an audio/language model to resolve ambiguity.
